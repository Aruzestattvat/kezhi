# 选单助手课值微信小程序 1.0.0

这是从现有桌面版独立拆出的微信小程序框架，不会修改或覆盖桌面版。

## 当前已经具备

- 首页订单排行、搜索、状态筛选、群聊筛选和星期筛选。
- 支持按实际净时薪或预估月收入切换排行模式。
- 预估月收入按单次课时收入 × 每周次数 × 每月 4.33 周计算。
- 打车、公交车、共享电单车、自行车、自由出行切换。
- 每种出行方式单独保存路线缓存，切换回来不会重复计算。
- 群聊分页、清空单个群聊订单、选择是否同时删除群聊。
- 在导入文本框中长按粘贴微信群消息，按发送人时间、订单号及字段组分单；导入后自动计算本次新增或更新且地址明确的订单。
- 复用桌面版的价格、时长、频次、地址、性别及专职老师识别规则。
- 收藏、完整信息复制、单条重算及未完成订单补算。
- 本地数据管理和三级删除范围。
- 固定使用高德云端路线，设置中不再提供路线服务切换。
- `route` 云函数：Key 仅保存在云函数端，不写入小程序客户端。

## 在微信开发者工具中打开

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹 `work/miniapp`。
4. 暂时使用测试号，或者把 `project.config.json` 中的 `touristappid` 换成自己的 AppID。
5. 编译后，点击首页右上角“导入”，可先用“填入示例”体验。

路线计算固定调用微信云开发的 `route` 云函数；未部署云函数时，订单导入、识别、筛选和收藏等本地功能仍可使用。

请将 `app.js` 中的 `YOUR_CLOUD_ENV_ID` 替换为自己的云环境 ID，开发者工具中的 `cloudfunctions` 根目录也应选择同一环境。

## 接入真实高德地图

1. 在微信开发者工具中开通云开发并选择环境。
2. 右键 `cloudfunctions/route`，上传并部署云端安装依赖。
3. 本源码包不包含地图密钥或 `secret.local.js`。
4. 在云函数环境变量中添加自己的 `AMAP_WEB_SERVICE_KEY`。
5. 不要把 Key 写入小程序页面、`app.js` 或提交到公开仓库。

真机计算前必须确认 `route` 已经上传到当前云环境。仅点击“编译”不会部署云函数；需要右键 `cloudfunctions/route`，选择“上传并部署：云端安装依赖”。如果手机端失败，可在云开发控制台的云函数日志中按时间核对具体原因。

小程序固定使用云端高德地图，不需要用户在设置中选择。

当前云函数按低额度策略只查询单程路线，往返距离、时长和费用按单程两倍估算；公交保留站台与换乘信息。
