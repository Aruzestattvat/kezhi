# 课值 v0.2.2 内测须知

感谢参与课值的早期测试。本版本用于少量可信用户验证微信群消息分单、字段识别、地图定位与收益计算。

本次更新新增打车、公交车、共享电单车、自行车和自由出行五种模式；不同方式的路线结果会分别缓存在本机，切回已经算过的方式不会重复调用地图。切换提示只显示待补算数量或“已全部计算完毕”。各方式保留各自的路线距离，因此20公里自动 PASS结果可能不同。公交显示单程推荐站台和换乘方案，其余方式按内置规则估算费用。此前的 JXOT/JXQT、多订单拆分和紧凑薪资识别均保留。

## 启动

1. 解压整个压缩包，不要只把 EXE 单独拖出来。
2. 双击 `课值内测版.exe`。
3. 保持终端窗口开启，浏览器会自动打开 `http://127.0.0.1:8765`。
4. 使用结束后关闭终端窗口即可停止本地服务。

若浏览器没有自动打开，请手动访问上述地址。若提示端口被占用，先关闭之前启动的课值终端窗口。

## 内测 Key 与隐私

- 内测包预置了共享的高德 Web 服务 Key，请勿把压缩包或 Key 转发给非内测人员。
- 微信群消息、群聊页面、收藏和地图设置只保存在当前浏览器本地，不会上传到课值服务器。
- 路线计算时会把出发点、家教地址和地图 Key 发送给高德地图。
- 内测结束后，开发者可能停用或更换共享 Key。

## 请重点检查

- 一段聊天记录是否被正确分成多条订单。
- 年级、科目、地址、薪资、每次时长和每周次数是否正确。
- “南湖、秀洲、桐乡、海宁、平湖、嘉善、海盐”等行政区是否定位正确。
- 地图定位地址、往返距离和打车费是否符合常识。
- 收藏、复制、群聊分页、清空与二次确认是否正常。

当前已知：同名小区或地址缺少区县时，地图偶尔可能选到嘉兴其他区县。发现路线明显过远时，请不要依据该收益结果接单，先记录原文、地图定位和截图后反馈。
