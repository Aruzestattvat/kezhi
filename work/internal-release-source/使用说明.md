# 课值 · 家教订单性价比助手

课值会把手动粘贴的微信群家教消息整理成订单，并按打车、公交车、共享电单车、自行车或自由出行的通勤时间与费用计算净收益和实际净时薪。软件不会登录微信，也不会自动读取微信账号。

## 第一次使用

1. 双击 `课值内测版.exe`。浏览器会自动打开 `http://127.0.0.1:8765`，终端窗口需要在使用期间保持开启。
2. 内测版已预置测试用高德 Web 服务 Key，无需首次填写；请勿把安装包或 Key 转发给非内测人员。
3. 在订单列表上方选择出行方式；如需改用自己的地图密钥，可以点击左侧齿轮，在设置中更换高德 Key 或百度 AK。
4. 核对出发点。默认是“嘉兴大学梁林校区”，建议换成日常开车出发的具体校门。
5. 点击“导入群消息”，直接粘贴连续的微信记录，然后选择“识别并加入”。

可以直接复制微信里带有发送时间、表情和多行字段的一整段记录。程序会忽略单独的 `[聊天记录]` 占位块，并从 `育林1002689` 这类文字中提取订单号；同一订单号重复出现时，以本次粘贴中较晚的一条为准。

程序优先把“发送人昵称 + 下一行微信时间”识别为一条新订单的开头。发送人不会写死，可以是同一个人，也可以在一段记录中交替出现多个不同发单人；订单正文里的自动换行和空行不会再被当成分单信号。支持 `2026年08月26日 13:35`、`2026/8/26 13:35`、`8月26日 星期三 13:35`、`昨天 13:35` 等常见时间行。没有发送人和时间时，才会回退到订单编号与空行规则。

同一条微信消息中如果连续包含多个订单，程序会识别 `JXOT/JXQT + 数字`、`嘉兴`、`育林`、`dt`、`xc` 等编号并再次拆分；订单号前允许出现红旗、圆点等常见表情。没有固定字母前缀的 9–18 位长数字，也可以在后续同时出现地址、科目/内容、价格等至少两类订单字段时作为分割提示。常见 11 位手机号及形似日期时间的数字串会被排除。

## 群聊分页、收藏、复制与自动 PASS

- 导入时填写的“来源群别名”会自动成为一个群聊页面。可以在订单列表上方的下拉框切换，也可以点击左侧“群”按钮打开分页管理。
- 再次导入时，可以在“导入到群聊”下拉框中直接选择已有群聊；需要新建时选择“＋ 新建群聊”并填写名称。
- 选中一个具体群聊后，可以点击“重算本群”重新查询该群所有地址明确且未 PASS 的订单。执行前会再次显示订单数量并要求确认；在“全部群聊”页面不能触发，避免误耗地图额度。
- “清空本群订单”会打开二次确认窗口并显示群名与订单数量。默认只删除订单、保留空群聊页面；勾选“同时删除群聊页面”后，才会连同该群页面一起删除。其他群聊、地图密钥和计算设置不受影响。“全部群聊”页面不能触发该操作。
- 每条订单右侧都有“收藏”按钮。收藏内容以独立快照保存在本机；之后即使清空原群订单，仍可在“★ 收藏夹”中查看和复制这条订单。
- 每条订单右侧都有“复制完整信息”按钮，会复制群聊原文以及地址、薪资、课时、车费和实际净时薪摘要。
- 页面顶部和设置窗口中的“清空所有订单”会打开二次确认菜单。普通订单一定会删除；“同时删除所有群聊页面”和“同时删除收藏内容”均默认不勾选，只有主动勾选后才会一并删除。取消或不勾选收藏选项时，收藏夹不会受到影响。
- 在订单列表上方选择“我是男老师”或“我是女老师”后，仅推荐性别要求相符或“男女不限”的订单；不相符的订单会进入“已 PASS”筛选页。
- 教员要求中明确写有“在职、专职、全职、在编、一线、学校、机构或退休老师/教师”的订单会自动 PASS，并且不会请求地图计算路线，避免浪费接口额度。“有教师资格证”“有教学经验”不会触发该规则。程序只在“教员要求/老师要求”等要求字段中判断性别，不会把“学员情况：五年级男生”误判成教员性别要求。
- 出现“报销路费”“报销车费”“补贴路费”“补贴车费”“车补”或“实报实销”等描述时，个人实际交通支出按 ¥0 计算；“不报销路费”等否定写法不会触发。地图仍会用于测算通勤距离与时间。

## 百度地图服务端 AK 是什么

AK 是百度地图开放平台分配给应用的访问密钥。课值拿它调用“地址转坐标”和“驾车路线规划”接口，并从路线结果中读取 `taxi_fee`。它不是百度账号密码，也不是浏览器端或微信小程序 AK。

获取步骤：

1. 打开 [百度地图开放平台 API 控制台](https://lbs.baidu.com/apiconsole/key)，登录百度账号并完成个人开发者认证。
2. 进入“应用管理”→“我的应用”→“创建应用”。
3. 应用名称可填写“课值”。
4. **应用类型选择“服务端”**，不要选择浏览器端、Android、iOS 或微信小程序。
5. 在启用服务中确保包含“地理编码”和“驾车路线规划/路线规划服务”。
6. 按控制台提示配置请求校验。若使用 IP 白名单，应填写电脑当前的公网出口 IP，而不是 `127.0.0.1`。
7. 提交后复制生成的 AK，粘贴到课值左侧齿轮中的“百度地图 AK”。

AK 会计入你的百度地图调用配额，请不要发布到群聊、截图或公开仓库中。

## 高德 Web 服务 Key

1. 打开 [高德开放平台控制台](https://console.amap.com/dev/key/app)，登录并按平台要求完成开发者认证。
2. 创建一个应用，例如“课值”。
3. 添加 Key 时，服务平台选择 **Web 服务**，不要选择 Web 端（JS API）、Android、iOS 或微信小程序。
4. 复制 Key，在课值设置中把地图服务商切换为“高德地图（省额度）”，粘贴到“高德 Web 服务 Key”。
5. 保存设置后点击“补算未完成”。

高德模式会缓存本次运行中已经解析过的地址。高德打车、公交、共享电单车和自行车都只请求一次去程路线，再按相同去程折算返程，以节省调用额度；返程因道路方向、站台或实时路况产生的差异不会单独体现。

## 五种出行方式

- **打车**：使用当前选择的百度或高德驾车路线及地图返回的预计打车费。
- **公交车**：固定使用高德公交路线，显示推荐线路的上车站、下车站、单程乘车次数和换乘次数。每乘坐一段公交或轨道交通按 ¥2 估算，因此往返费用为 `单程乘车次数 × ¥2 × 2`。
- **共享电单车**：固定使用高德电动车路线的单程时长。每个单程 10 分钟内 ¥2；超过 10 分钟后，每开始一个新的 10 分钟区间增加 ¥1.5；往返按两个相同单程估算。
- **自行车**：固定使用高德骑行路线的单程距离。每个单程每开始 5 公里计 ¥5 电解质水；单程达到 10 公里后额外计 ¥10 零食；往返按两个相同单程估算。
- **自由出行**：个人出行费用固定显示 ¥0。程序仍使用当前百度或高德驾车路线提供通勤距离和时间参考，用户自行决定实际交通方式。

公交、共享电单车和自行车采用高德单程路线折算返程，以节省接口额度。返程站台、实际候车时间、共享车辆可用性、临时交通管制和真实收费可能不同，结果仅用于接单前的保守比较。

如果双击脚本提示没有 Python，请先安装 Python 3。更新后的启动脚本会优先使用 Codex 自带的 Python；也可以在本目录运行：

```powershell
python server.py
```

## 计算口径

```text
单次课时收入 = 每小时单价 × 每次授课小时
往返交通投入 = 当前出行方式的估算往返费用
单次净现金收益 = 单次课时收入 - 往返交通投入
实际净时薪 = 单次净现金收益 ÷（授课时间 + 往返驾驶时间 + 缓冲时间）
预计月净收益 = 单次净现金收益 × 每周次数 × 4.33
投入产出比 = 单次课时收入 ÷ 往返交通投入
```

地图路线和程序计费均为估算值。实际打车价格可能受到车型、时段、平台优惠和动态加价影响；公交票制、共享电单车平台定价以及骑行补给也可能与程序设定不同。

“计算设置”中的“家教所在城市”会自动拼到每个订单地址前再交给地图，例如 `嘉兴市 + 南湖区大朱楼`。右侧详情同时显示“地图查询”和地图服务返回的“地图定位”地址，便于核对同名小区。默认最大单程距离为 20 公里；路线结果超过该值会自动进入“已 PASS”，可在设置中修改阈值。

页面顶部的“补算未完成”只会查询车费为空、为 0 或尚未成功得到费用的订单，已经具有正常车费的订单不会重复请求。按钮会显示待补算数量和当前进度。为了避免同时请求过多导致百度限流，订单会逐条计算；地址缺失或“老师家/图书馆”这类模糊地址会被跳过，需要先编辑确认。

## 消息示例

```text
初二数学，地点巴黎都市，周六下午2点到4点，120元/小时

高一物理，江南摩尔附近，周日19:00-21:30，150元每小时，每周2次

小学六年级英语，地址禾源新都，晚上7点半到9点，100元一次
```

支持的主要价格写法包括：`120元/小时`、`每小时150`、`200元/2小时`、`150元一次，一次2小时`。含义不明确的字段会显示为“待确认”，可以打开订单手动修改。

紧凑写法 `55/h1.5h`、`90/h2h` 也会分别识别为“每小时 55 元、每次 1.5 小时”和“每小时 90 元、每次 2 小时”。

也支持群内常见的区间和紧凑写法：

- `老师薪水：70-75/h`：保留 70–75 元区间，排名按 70 元保守计算
- `一次4h，160-200每次`：识别为每次总价 160–200 元，换算为 40–50 元/小时；不会把“一周2次”中的“2次”误认成价格
- `时间安排：一周2-3次，一次2h`：每周 2–3 次，每次 2 小时
- `周1356`：识别为每周 4 次
- `周一到周五中选2天`：识别为每周 2 次
- `135或246晚上9-10点`：识别为每周 3 次、每次 1 小时
- `周六下午2-3h`：识别为每次 2–3 小时，收益按 2 小时保守计算

“上老师家或者图书馆”这类没有具体目的地的描述会标记为“地址需确认”，不会直接发给地图计算。请编辑成具体小区、道路或图书馆名称后再计算。

地址采用严格前缀识别，只读取“学员地址、学生地址、上课地址、授课地址、辅导地址、上课地点、辅导地点、地址、地点、住址、家住”等标签后的文字，也支持 `【上课地址】：`、`[学员地址]:` 这类带方括号的格式。没有这些明确标签时，订单会显示“地址待确认”，避免把“嘉兴安欣老师（发单人）”之类的发布者信息误当成地址。

从微信复制时产生的零宽字符及 `&#x20;`、`&nbsp;` 等空格标记会自动清理；`嘉兴082135`、`育林1002689`、`dt26082404`、`xc081801l`、`JXOT2666082601` 这类订单编号同样可以作为备用分单标记。复制结果中如果混入“——课值测算——”摘要，摘要块会被忽略，不会再次导入成订单。

只有“薪资：75/h 2h”之类价格和时长、但没有年级科目或地址的孤立碎片不会生成订单；如果该碎片紧跟在一条完整订单后，则会自动合并回上一条订单。

更新前已经误合并并保存在浏览器中的订单，会在新版页面启动时根据多个嘉兴、育林、dt、xc、JXOT/JXQT 或有效长数字订单编号自动重新拆分并去重，无需先手动删除旧订单。

授课时长会优先从具体时间段自动推算，例如：

- `周六下午2点到4点` → 2小时
- `19:00-21:30` → 2.5小时
- `晚上7点半到9点` → 1.5小时
- `上午9点到下午1点` → 4小时
- `每次90分钟` → 1.5小时
- `一个半小时` → 1.5小时

如果文本完全没有给出时间段或明确时长，系统才使用设置中的默认值，并将该订单标记为“授课时长确认”，避免把默认值误当成家长已经确认的时间。

## 数据与隐私

- 订单、群消息、收藏快照和百度 AK 保存在当前浏览器的本地存储中。
- 群聊分页设置和高德 Key 同样只保存在当前浏览器。
- 本地服务器只监听 `127.0.0.1`，局域网中的其他设备无法直接访问。
- 查询路线时，只向当前路线所需的地图服务商发送出发点、目的地坐标或地址以及对应密钥。公交、共享电单车和自行车固定请求高德地图。
- 服务器日志不记录请求正文或 AK。
- “清空所有订单”会要求二次确认；群聊页面和收藏内容只有勾选对应选项时才会一并删除。已经删除的内容无法恢复。
- 导出的 CSV 不包含原始群聊文本。

## 常见问题

### 路线计算提示 AK 无效

检查百度地图控制台中的应用类型是否为服务端，以及是否启用了地理编码和驾车路线规划。若配置了 IP 白名单，需要允许当前公网出口 IP。

### 提示“无法连接百度地图”

这表示本地 Python 服务还没收到百度服务器的响应，通常不是地址识别问题。请确认使用的是你自己双击 `启动课值.bat` 后打开的页面，并保持弹出的终端窗口不要关闭；随后检查电脑能否访问百度地图、代理或防火墙是否阻止 Python 联网。若页面是由 Codex 测试时启动的受限服务，请先关闭它，再自行双击启动脚本。

### 百度没有返回打车费

可能是当前 AK 权限、配额或路线接口产品不同。可以打开订单，在“往返出行费”中手动填写实际价格，其他收益指标会自动重算。

如果百度返回的打车费为 `0`，课值会把它标记为“费用异常”，不再按免费通勤参与性价比排名。可以先点击“补算未完成”；若多次仍为 0，请检查地址定位是否正确，或在订单编辑窗口手动填写百度地图 App 中显示的往返价格。

### 地址定位不准确

把“小区附近”改成更完整的“嘉兴市 + 区县 + 小区/道路”，或者补充校门、楼盘名称。页面会显示百度返回的地址可信度。

### 端口 8765 已被占用

先关闭之前打开的课值命令窗口，然后重新启动。

### 双击启动脚本后窗口立刻关闭

更新后的启动脚本不会再静默关闭：启动失败时会停留并显示原因。如果仍然失败，请截图终端中的完整错误文字。常见原因是 Python 不可用、端口 8765 已被其他课值进程占用，或安全软件阻止本地服务器。
