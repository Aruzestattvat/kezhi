# 课值桌面版

## 启动

解压完整压缩包后，双击“课值.exe”。应用会在后台启动本地服务，并使用 Windows 设置的默认浏览器打开课值，不需要安装 Python，也不会显示终端。

推荐使用最新版 Google Chrome 或 Microsoft Edge。其他浏览器也可以尝试使用，但剪贴板、本地数据保存和页面布局以 Chrome、Edge 为主要兼容目标。如需切换，请先在 Windows“默认应用”中修改默认浏览器。

## 退出

启动后会保留一个小型“课值正在运行”控制窗口。可以用其中的“打开课值”重新打开页面；点击“退出”或关闭该控制窗口后，本地服务会停止。再次使用时重新双击“课值.exe”即可。

## 数据位置

订单、群聊、收藏、地图设置和路线缓存保存在默认浏览器的本机数据中，不会上传到课值服务器。同一台电脑更换默认浏览器后，旧浏览器中的订单不会自动迁移，需要重新导入群消息。

## 分发

请发送完整压缩包，不要只发送 exe。接收方需要先完整解压，再运行“课值.exe”。

此源码副本已移除共享高德地图 Key；运行后请在设置中填写自己的 Web 服务 Key。
