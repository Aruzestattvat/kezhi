# 课值桌面版构建说明

## 架构

- `internal-release-source/server.py`：只监听 `127.0.0.1` 的本地 Web 服务及地图代理。
- `internal-release-source/desktop.py`：无终端桌面启动器，启动服务后调用 Windows 默认浏览器，并提供打开页面和退出服务的控制窗口。
- `pyinstaller-spec/课值桌面版.spec`：PyInstaller 无终端 one-folder 构建配置，包含页面资源、说明文件和 App Logo。

推荐用户使用最新版 Google Chrome 或 Microsoft Edge。程序遵循 Windows 默认浏览器设置，不会强制指定浏览器。

## 构建环境

1. Windows 10/11 x64。
2. Python 3.12。
3. PyInstaller 6.22.0。

首次构建时，在项目目录安装依赖：

```powershell
python -m pip install --target work/pyinstaller-build-deps pyinstaller==6.22.0
```

## 构建命令

在项目根目录执行：

```powershell
$env:PYTHONPATH=(Resolve-Path 'work/pyinstaller-build-deps').Path
python -m PyInstaller --clean --noconfirm `
  --distpath 'work/desktop-dist' `
  --workpath 'work/desktop-build' `
  'work/pyinstaller-spec/课值桌面版.spec'
```

构建结果位于 `work/desktop-dist/课值桌面版-v1.0.0-rc1-20260829/`。

## 发布原则

- 发布 one-folder ZIP，不单独发送 exe。
- 每次发布前运行解析测试、出行方式服务测试和解压启动测试。
- 为发布目录生成 `SHA256SUMS.txt`，并记录 ZIP 的 SHA-256。
- 此源码副本不包含共享地图 Key；每位使用者需在设置中填写自己的 Key。
